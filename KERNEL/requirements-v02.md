
# Goal - Deduplicate

"Deduplicator - a kind of conversion"

At the top of Converter there will be new functionality:

A vertical text box where a user can paste in newline delimited strings

- an optional button that allows the input to be split by whitespace into newlines)
- an optional button that sorts the strings 

A "Deduplicate" button...
A second output section on the right where the input on the left is "converted" into a deduplicated list.
- optional "to lower" and "to upper" buttons that would transform all the output text

First pass: just use exact matching in code (do not use regex)
